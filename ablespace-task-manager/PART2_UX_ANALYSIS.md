# Part 2 – Product Understanding

## Workflow to document

The assessment asks the candidate to explore the AbleSpace Take Data screen from the Caseload tab and submit either a screenshot-based document or a video walkthrough.

## Suggested walkthrough structure

1. Open the Caseload area.
2. Select the relevant learner/caseload item.
3. Open the Take Data workflow.
4. Identify the data-collection target.
5. Enter the observation/data point.
6. Save/submit the data.
7. Review the resulting record/history.
8. Explain where the collected data can be reviewed and how it supports progress tracking.

## UX improvement framework

### 1. Reduce cognitive load

Keep the active learner, target, and measurement type visually persistent while entering data.

### 2. Faster repeated entry

Provide keyboard shortcuts and a clear "Save & next" action for users collecting data across multiple targets.

### 3. Error prevention

Validate incomplete observations before saving and explain exactly what is missing.

### 4. Progress feedback

Show a lightweight progress indicator when a user is working through multiple targets.

### 5. Recent history

Provide quick access to recent entries so users can confirm that the observation was saved correctly.

### 6. Accessibility

Ensure controls have visible focus states, sufficient contrast, keyboard navigation, and descriptive labels.

> Important: This is a draft product-analysis framework. The final Part 2 submission should be written after personally exploring the live AbleSpace Take Data workflow and inserting screenshots from that workflow.
